# grossi.com.br

Repositório do site estático hospedado via **GitHub Pages** e acessível pelo domínio customizado [grossi.com.br](https://grossi.com.br).

## Sobre

Página estacionária servida diretamente pelo GitHub Pages.

## Stack

- HTML puro
- Fonte: [UnifrakturMaguntia](https://fonts.google.com/specimen/UnifrakturMaguntia) via Google Fonts
- Hospedagem: GitHub Pages
- DNS: Registro.br

## Estrutura

```
grossi.com.br/
├── index.html   # página principal
├── CNAME        # domínio customizado lido pelo GitHub Pages
└── README.md    # este arquivo
```
